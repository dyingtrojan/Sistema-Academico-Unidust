# Sistema Acadêmico UniDust
## Problematica
Em um sistema educacional, como escolas, universidades e cursos alheios, muitos alunos e professores possuem dificuldades para gerenciar as atividades acadêmicas e acessar o boletim. 

Com o avanço da tecnologia, é muito beneficente e necessário um sistema digital em que os professores podem publicar as atividades escolares, e os alunos conseguem acessá-las por meio do mesmo sistema. 

Além disso, é necessário o controle de administradores para a criação de cursos e disciplinas
